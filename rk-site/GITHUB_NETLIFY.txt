GITHUB + NETLIFY STEPS

1. Is zip ko khol lo. Andar rk-site folder hai.
2. GitHub par repo kholo (jo abhi site ka hai). Purani index.html ki jagah ye rakho:
   public/index.html, public/image/ (poora folder), public/admin.html, public/firebase-config.js
   netlify.toml repo ke sabse upar (root) me rakho.
   Purane pages (about.html, courses.html etc) agar repo ke root me hain to unhe public/ folder me daal do.
   Commit karo.
3. Netlify: Site configuration > Build and deploy > Publish directory = public. Build command khaali.
   (netlify.toml ye khud set kar deta hai.) Deploy hone do.
4. Firebase Console > Authentication > Settings > Authorized domains me apna Netlify domain
   (jaise yoursite.netlify.app) aur custom domain dono add karo.
5. Firebase Console > Firestore > Rules me firestore.rules ka poora text paste karke Publish karo.
   Admin email isme pehle se daal di gayi hai.
